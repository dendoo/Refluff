# id (Indonesian) review

Verdict: OK after fixes

Natural Indonesian gamer copy. It uses kamu / -mu, as the game does (Perkuat peralatanmu, saat kamu belanja).
Glossary terms are used consistently: Pengikis, Sikat (sikat putar), Wiper, Penyedot air, deterjen, alat pel,
Serahkan, DAYA / CAKUPAN in capitals, bonus kecepatan / tanpa noda / kering kerontang / combo, and lampu inspeksi
(the shop caption is INSPEKSI).

The vocabulary is Indonesian throughout, with no Malay words: busa, serat, uang, acak, membandel, ubin, merah muda,
cokelat, antarmuka, kartu grafis, perangkat, kompatibel, disarankan, lebih baru, Lisensi. Lists use the comma before
dan, as Indonesian spelling rules (EYD) require. The system requirements follow Steam's Indonesian wording
(Memerlukan prosesor dan sistem operasi 64-bit, atau lebih baik).

Wiper: this is the natural everyday word for a squeegee in Indonesia. Floor squeegees are sold and searched for as
"wiper lantai", and window squeegees as "wiper kaca". The game's tool name is Wiper, so the store page must use it too.
It reads naturally in "dorong air kotornya dengan wiper".

## Changes
- hdr_water: Air nyata, lumpur nyata -> Air dan lumpur sungguhan
  (fluency: nyata means "real" as opposed to imaginary (dunia nyata), and "air nyata" is an English calque that no
  Indonesian would write. sungguhan is the natural word here, and the translator's own note says so. The two-part form
  with sungguhan would be 31 characters, too long, but Air dan lumpur sungguhan fits at 24 characters and is consistent
  with "simulasi fluida sungguhan" in the short description and water_body. No Indonesian header images have been
  rendered yet, so none is out of date.)
- short_description: ...lalu keringkan seratnya hingga karpet tanpa noda. -> ...lalu keringkan seratnya hingga karpet bersih tanpa noda.
  (fluency: "hingga karpet tanpa noda" has no predicate and reads cut off. "bersih tanpa noda" is the idiomatic pair and
  keeps the glossary's Tanpa noda. Now 298 of 300 characters.)

## Doubts (left as written)
- headphones_body: berkeletak is a real word but a rare one. bergemeretak would be the more common word for a rattle.
  The sound picture is clear, so it was kept.
- short_description: seratnya appears twice (basahi seratnya ... keringkan seratnya). It is a little repetitive, but it
  could not be changed within the 300-character limit without losing a step.
